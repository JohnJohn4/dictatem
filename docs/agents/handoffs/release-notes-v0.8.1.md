## v0.8.1: the tray menu behaves like other Windows apps

### Tray menu (Windows)
- **Left-click the icon to open the menu.** Right-click still works.
- The menu is now Windows' own menu, so it behaves like every other tray app:
  - the hidden-icons box (the `^` by the clock) **stays open** while you use
    the menu;
  - **clicking elsewhere closes the menu**, even with "How to use Dictatem"
    open (previously it could stay stuck until the guide was closed);
  - arrow keys and Esc work.
- Tip: pin Dictatem next to the clock via **Settings → Personalization →
  Taskbar → Other system tray icons → Dictatem**.

### Updating
Use **Check for updates…** in the tray. Coming from v0.8.0 this is a quick
update.
