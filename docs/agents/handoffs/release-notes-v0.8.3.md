## v0.8.3: find Dictatem in the Start menu

### New
- **Dictatem is now in the Start menu.** If you Quit it, press the Windows key,
  type **Dictatem** and press Enter to start it again (or use Win+R →
  `dictatem`). With **Start at login** on, it also starts at your next sign-in.
- The installer says how to start it again, and `dictatem --uninstall`
  removes the shortcut.

### Updating
Use **Check for updates…** in the tray. The update adds the Start-menu
shortcut.
